# Bets Board Case Study

## Özet

React ve Redux Toolkit kullanılarak geliştirilmiş responsive bir spor bahis bülteni uygulaması.

---

## Özellikler

- Axios ile API'den veri çekme
- Redux Toolkit ile state yönetimi
- Async işlemler için createAsyncThunk kullanımı
- Desktop için board/table yapısı
- Mobile için card yapısı

---

## Kullanılan Teknolojiler

- React
- React Hooks
- Redux Toolkit
- Axios
- Webpack
- Sass
- Jest / React Testing Library

---

## Tasarım

UI tasarımı oluşturulurken Google Stitch (AI) referans alınarak projeye uygun şekilde manuel olarak uygulanmıştır.

---

## Kurulum

bash npm install npm start
